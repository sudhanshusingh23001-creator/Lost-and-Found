 🚀 Campus Lost and Found (KhoyaPaaya)
 
A web-based platform designed to help students reunite with their lost belongings on campus.

 🛠️ Tech Stack
-Backend: FastAPI (Python)
- Database: SQLite
- Frontend: HTML5, CSS3, JavaScript

 📂 Project Structure
- `main.py`: The core FastAPI application and API routes.
- `static/`: Contains all CSS and Client-side JavaScript.
- `templates/`: Contains the HTML layout.

 🚀 How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Run the server: `python main.py`
3. Access at: `http://127.0.0.1:8000`
